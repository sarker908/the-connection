# The Connection

An interactive knowledge universe connecting people, inventions, discoveries, events and ideas across six domains.

## Explore
- Interactive knowledge graph powered by Cytoscape.js
- Search across topics and descriptions
- Topic details with related connections
- Connection Finder using breadth-first search
- Timeline of selected discoveries
- Local bookmarks in My Discoveries

## Run locally
Open `index.html` through a local static server (for example, VS Code Live Server). The JSON data is loaded with `fetch`, so opening the file directly may block data loading.

## Deploy
Enable GitHub Pages in **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

No backend, paid API, or account is required. Cytoscape.js is loaded from a public CDN.
